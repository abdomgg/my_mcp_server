MCP SERVER · AI GATEWAY FOR ODOO

The front door AI agents use to reach Odoo — and the lock you keep on it

Connect any AI assistant straight to your database — then decide exactly what it's allowed to see, touch and run. Every workspace, key and model-access rule is deny-by-default until you say otherwise.

Stop choosing between "no AI access" and "full superuser AI access"

Most ways of connecting an AI client to an ERP give it one shared key with broad permissions, or nothing at all. MCP Server sits in between: every key is scoped per model, per field, per row, logged in full, and off by default until you explicitly grant it.

Split every client, team or environment into its own tenant

Each tenant gets its own rate limits, its own allowed-companies list, and a single toggle to shut it off — no code changes, no restart.

Scope a key to exactly what it's for, nothing else

Switch on BI/Reporting, Exports, Batch/Async, Portal Pages or Module Builder independently per key. Run a key as a specific user, set an expiration date, and rotate its token in one click.

Onboard your AI assistant without handing out a shared secret

Register a client, lock it to an approved sign-in address, and require secure verification on every connection. Each person who authorizes gets their own key cloned from an access template — individually auditable, never a static shared secret.

A permission matrix, not a permission checkbox

Grant read, create, write and unlink independently per model, per key. Narrow further with a field allowlist, a domain filter and a row cap. No row for a model means the model doesn't exist to that key.

Watch the gateway the way you'd watch any production service

Requests, success rate, latency, denials, errors and rows touched over 1h/24h/7d/30d, plus top tools, slowest tools, busiest keys, tenant health and a live activity feed.

Let large operations run in the background

Frequently asked questions

Does an AI client bypass Odoo's own security?

No. MCP Server is an integration gateway. It runs externally and calls approved tools through Odoo's own security layer — it does not bypass Odoo security.

What happens if I don't configure a model's access?

Nothing — no rows means no access. Every model is deny-by-default until you add an explicit access rule for a key.

Can I connect my AI assistant directly?

Yes, through a secure sign-in flow. Each person who authorizes gets their own individually-audited key cloned from an access template.
